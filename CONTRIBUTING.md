# Cómo contribuir

1. Crea un fork del repositorio.
2. Crea una rama para tu cambio con un nombre descriptivo.
3. Mantén el código PHP legible y escapa la salida que proceda de usuarios.
4. Comprueba manualmente el ejercicio modificado en un servidor PHP local.
5. Abre una Pull Request explicando el cambio.

Actualiza el `README.md` o el `CHANGELOG.md` cuando el cambio afecte al uso o al
comportamiento del proyecto.
